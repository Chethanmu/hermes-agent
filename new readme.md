# Hermes Agent ☤

Hermes Agent is an open-source autonomous AI agent built by Nous Research.  
It is designed to run persistently on your machine or server, remember past interactions, and improve itself over time through reusable skills and long-term memory.

## Features

- Persistent memory across sessions
- Self-improving skill system
- Multi-platform integrations
- Support for multiple LLM providers
- Open-source and self-hosted
- Works on Linux, macOS, and WSL2

## Supported Platforms

- Telegram
- Discord
- Slack
- WhatsApp
- Signal
- CLI Interface
